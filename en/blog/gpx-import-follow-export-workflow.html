GPX & maps

The full GPX import, follow, record, and export workflow

GPX helps move route data between compatible tools instead of locking a record into one app. RouteTracker treats an imported reference route, the real GPS recording, and the exported completed activity as distinct parts of one workflow.

HayanNamuApps product teamPublished: 2026-07-22Updated: 2026-07-22

The imported route and live recording are different data

An imported GPX is a reference for where you plan to travel. RouteTracker displays that line on the map, then records your real hiking, cycling, running, or walking movement separately from device GPS when you start an activity.

The imported file does not automatically become a completed activity. The reference route and that day's real track are used together in the map workflow.

The GPX round trip

  1. Prepare a GPX file from a source you trust and inspect its start point and expected distance.
  2. Import it into RouteTracker and compare the route line with your current position.
  3. Start a new recording with the correct activity type and use the imported line as a reference.
  4. Finish normally, then review the real route map and core distance and time metrics.
  5. Export the completed activity as GPX and save it with a name distinct from the original reference route.

Why verify the exported file

Opening the exported GPX once in another compatible viewer independently confirms that the file exists and covers the expected route. For an important record, also review its date, activity type, notes, and RouteTracker detail rather than relying on the file alone.

Compatible tools can interpret extension fields differently, so metrics beyond the route geometry may not look identical in every GPX app.

Limits to check before use

  • An imported GPX is a reference route, not a guarantee of turn-by-turn navigation, access rights, safety, or current trail and road conditions.
  • The live track depends on device GPS quality and may not overlap the reference line exactly.
  • Non-standard extension fields used by another GPX app may not survive an import or export unchanged.
